Set up Sharepane

Sharepane lets Claude read the Firefox tabs you choose. Each step below turns green by itself once it's done.

  1. Install the extension

    Done: you're looking at it.

  2. Connect the helper

    Checking…

  3. Allow access to your local dev servers

    Sharepane has lost its access to localhost and 127.0.0.1, so tabs on your local dev server can't be read.

  4. Connect Claude

    Waiting for the helper first.

  5. Allow a tab

    Open the site you're working on, click the Sharepane toolbar icon, and choose Allow.

You're set up

Ask Claude about the tab you allowed, for example: "Why does the button on my page look misaligned?"

Claude can read console logs, network requests and screenshots too, once you turn them on in Settings. All of them start off.

Nothing leaves your computer. Sharepane talks only to a helper program Firefox starts on it.
