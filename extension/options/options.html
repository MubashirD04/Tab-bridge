Tab Bridge — Settings

Tab Bridge never sends anything anywhere except 127.0.0.1 on this machine. It only reads tabs you explicitly allow, or tabs on a trusted local dev port — nothing else, and nothing is written to disk unless you turn on the (separate, opt-in) recording feature.
Matches the port the tab-bridge start daemon printed on startup.
Run tab-bridge start once to generate it, then copy the token field from ~/.tab-bridge/config.json here.

Trusted local dev ports

Any tab open on 127.0.0.1/localhost at one of these ports is readable by Claude automatically — no click needed in the popup. Only add ports you actually run a local dev server on.
